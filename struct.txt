4. Спецификация исходящего HTTP-запроса к клиентуКогда Dispatch Worker выполняет вызов клиентского эндпоинта, он формирует следующий HTTP POST-запрос:HTTPPOST /webhooks HTTP/1.1
Host: api.merchant.com
Content-Type: application/json
User-Agent: Webhook-Dispatcher/1.0
X-Event-ID: evt_order_129381029
X-Event-Type: order.paid
X-Event-Timestamp: 1755543600
X-Signature-SHA256: t=1755543600,v1=9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08
traceparent: 00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01

{
  "event_id": "evt_order_129381029",
  "event_type": "order.paid",
  "timestamp": "2026-08-18T19:00:00Z",
  "data": {
    "order_id": "ord_9901",
    "amount": 4500,
    "currency": "USD"
  }
}
X-Signature-SHA256 формируется по стандарту Stripe: HMAC_SHA256(timestamp + "." + raw_body, secret_key). Это защищает клиента от Replay-атак.traceparent передает сквозной контекст OpenTelemetry в инфраструктуру клиента.
